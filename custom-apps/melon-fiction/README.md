# 吃瓜文学

界面叙事文学生成器：选几位角色当主角，AI 生成整场戏，你是屏幕外的吃瓜群众——蹲后续、催更、插楼。

第一版内置两种文体：

- **论坛体**：主角以匿名网友身份发帖，楼下是 AI 生成的吃瓜群像——蹲后续的、玩梗的、锐评的、站队的。楼层引用、楼主下场、点赞数即隐形叙事（名场面赞最高）。底部可以「催更」续楼，也可以以路人身份**插一楼**，后续楼层会自然接住你的发言。
- **聊天记录体**：偷看一部「被捡到的手机」里的私聊界面。左侧白气泡是对方（带头像和备注名），右侧黄气泡是手机主人。备注名本身就有梗，底部「继续往下翻」续更。

## 玩法

1. 「种一个新瓜」→ 选文体 → 点选主角（按顺序生效，最多 3 位）→ 可选填瓜的主题/梗概 → 开始吃瓜。
   - 论坛体：第 1 位是楼主，其余主角作为当事人/知情人被卷进瓜里。
   - 聊天体：选 1 位 → TA 是对方，手机主人由 AI 虚构；选 2 位 → 第 1 位是手机主人（右侧），第 2 位是对方（左侧）。
2. 生成基于 `AiPhone.ai.generate` 的统一预设链路：角色人设、记忆、世界书自动进入上下文，所以瓜会长在角色自己的性格和近况上。
3. 所有瓜保存在 APP 私有数据库，可随时回瓜棚重看、续更或删除。

## 技术要点（给创作者）

- 场景提示词在 `presets.json`，tags 分别为 `["melon", "forum"]` 和 `["melon", "chat"]`；输出用 `@楼` / `@右` / `@左` 等行级标记约定格式，前端解析渲染，解析失败时按原文兜底展示。
- 多主角走 `ai.generate({ characterIds })` 多角色模式；续更把历史生成作为 `messages` 传回，形成多轮链路。
- 用户「插楼」以 user 消息进入下一轮上下文，模型会让楼主或网友接住这层楼。

## 权限

- `characters.read`：选主角、取头像。
- `ai.generate`：生成楼层 / 聊天记录。
- `app.data.read` / `app.data.write`：瓜棚存档。
- `ui.toast`：操作提示。
